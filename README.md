A tiny program for make.fun's [One Sentence for a Traveler from 1800](https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb) bounty. It writes one sentence (164 characters) explaining the modern internet to a traveler from 1800 to `/output/entry.txt`:

> Imagine a coffee house where every soul on earth has gathered, so whatever you ask, someone there knows it, and your letter reaches any table before your cup cools.

A coffee house was the 1800 reader's newsroom, debating club and post room in one, so the whole internet becomes a single picture they can hold in their head: everyone on earth gathered in one room, any question answered, any letter delivered before your cup cools. No word in it was coined after 1800 — the program itself refuses to write the text if one slips in.

Run it with Node 22+:

```
node main.ts
```
